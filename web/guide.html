01 / BROWSER

打开链接就能体验模拟流程。

打开浏览器模拟工作台 ↗，点击「开始采集」。可以调整显示滤波、查看频谱，进入「实验与事件」发送标记或运行视觉刺激。

在线数据由浏览器生成，不是真实脑电，也不是 BrainFlow 模拟板。单次最长 10 分钟，数据暂存在当前页面；停止后下载 CSV，刷新前导出事件日志。此模式无需安装依赖，也不会请求 USB 或访问你的 localhost。

02 / LOCAL

连接真实设备，从本机启动。

下载并完整解压工作台，安装 Python 3.10+ 与官方 OpenBCI GUI。分发包复用 GUI 中的 Java 17 / BrainFlow 库，不包含这些依赖。

下载本地工作台 ↓Python 下载 ↗OpenBCI GUI 下载 ↗
  1. macOS：双击 launch.command；也可在解压目录运行 python3 launcher.py。
  2. Windows：运行 launch.bat，或 py -3 launcher.py。
  3. Linux：运行 sh launch.sh。
  4. 浏览器打开 http://127.0.0.1:8765/，保持服务终端运行。再次启动会打开已有工作台。

macOS 默认识别 /Applications/OpenBCI_GUI.app。其他位置设置 OPENBCI_GUI_DIR；库与 Java 分开安装时可设置 OPENBCI_BRAINFLOW_DIR 和 OPENBCI_JAVA，具体见分发包 README。

当前真实硬件验证平台为 Apple Silicon Mac + Rosetta，使用 OpenBCI GUI v6.0.0-beta.1 / BrainFlow 5.10.0。Windows 与 Linux 提供启动和配置入口，尚未完成实机验证。这是源码分发包，需要先安装上述依赖。

03 / CYTON + DAISY

先确认连接，再判断信号。

  1. 插入 Cyton USB 接收器，板子用电池供电，开关拨到 PC。
  2. 结束官方 GUI 中的采集会话，避免两个程序占用同一串口。
  3. 在本地工作台选择「Cyton + Daisy · 真实板卡」，选择 USB 接收器，再开始采集。
  4. 固件确认 16 通道响应后启动数据流，标称采样率 125 Hz。实际数据源、累计样本和记录时长显示在工作区顶部。

未佩戴电极时可收到板端数据，但悬空输入的漂移、噪声与饱和不能当作有效脑电。电极、参考及 BIAS 的连接请遵循 官方 Daisy 接线指南 ↗。

没有串口时，确认接收器已插入，再点击串口旁的刷新按钮；连接失败时检查板子电池、PC 开关、串口占用及记录目录中的 bridge.log。

04 / RECORDING

把原始数据和实验时序一起保留。

本地采集按会话自动保存到 recordings/，包含 raw.csv、events.tsv、metadata.json 与 bridge.log。点击「停止并保存」后可下载完整 ZIP。

「暂停显示」只冻结波形与频谱，采集和记录继续；显示滤波与量程不会改写原始记录。点击通道行可选择对应频谱，时间窗支持 4 秒和 8 秒。

原始信号有较大直流偏置时，微伏量程下可能看不到曲线。点击「适应信号」显示绝对电压；「原始信号居中显示」仅在绘图时减去窗内均值，通道旁保留均值注释，记录和频谱不变。接近默认 ±187.5 mV 边界时会提示输入饱和；居中、放大量程或滤波都不能恢复已丢失的变化。连续 3 秒无新样本会显示「等待新数据」，并保留最后收到的波形。

事件 A=1、B=2，空格可在实验视图中发送 A；输入控件聚焦时不触发。视觉刺激准备 1 秒，每次闪烁 150 ms。离开刺激工作区或将页面置于后台会取消剩余刺激。

浏览器计划时间、绘制回调时间、请求时间与标记所在样本分别记录。软件标记与绘制回调都不是硬件同步信号；正式刺激锁定研究需要外部触发或光电测量。前端日志需单独导出，刷新会清除。

05 / GITHUB

分享链接，也分享可运行的代码。

源码仓库：xiaozidian / OpenBCI ↗。项目采用 MIT 许可，可用于研究、修改与分发；第三方组件遵循各自许可。

  1. 在仓库 Settings → Pages 将 Source 设为 GitHub Actions。
  2. 向 main 推送代码后，工作流运行检查、生成分发 ZIP，然后发布 web/。
  3. 分享 在线工作台链接 ↗ 即可体验。真实硬件使用者从页面下载本地工作台。
  4. 自己分发可运行 python3 scripts/package.py，在 dist/ 获取 ZIP 与 SHA256 校验文件。

发布使用源码白名单，排除采集记录、调试证据、本机运行时和凭据。上传软件不等于上传实验数据。GitHub Pages 负责静态页面，USB 采集和原始保存由每位使用者自己的电脑完成。
