READING THE SIGNAL

频率里的信号

横轴是频率，纵轴是功率谱密度。某一频率的峰越高，表示这段数据中该频率的能量越集中。

频谱跟随当前显示滤波。模拟信号中的峰不能用于判断人的脑活动。

显示滤波与时间的含义

1–40 Hz 是一阶高通与低通串联的演示滤波；50 Hz 陷波 Q=30。它们只影响显示与频谱，不改变原始记录。Cyton + Daisy 时间戳为主机接收／合并时间；正式研究需另行验证滤波、信号质量和同步精度。

02 / 在本机连接硬件

下载工作台，接入真实板。

本地采集服务负责连接 USB 接收器与保存原始记录。需要 Python 3.10+，以及提供 Java / BrainFlow 库的 OpenBCI GUI。

下载本地工作台 ↓安装步骤 ↗

一次完整采集

  1. 连接与检查选择数据源。真实板需插入 USB 接收器，板子用电池供电并置于 PC。
  2. 观察与实验开始采集，调整显示。进入「实验与事件」添加标记或运行视觉刺激。
  3. 停止与导出点击「停止并保存」，下载采集记录和事件日志，保留实验配置。
